w/homelab - Kubernetes Homelab

Three Dell OptiPlexes and a Synology NAS in my house, running K3s. It started because I wanted Redis for this site and got out of hand from there.

  • GitOps: Everything deploys from Git through Flux and Helm. Secrets go in as Sealed Secrets, so they can live in the repo too.
  • Getting traffic in: Public requests hit a $5 DigitalOcean droplet and travel over WireGuard to Traefik in the cluster. My router has zero inbound ports open.
  • Storage: MetalLB for load balancers, and the Synology serves iSCSI and NFS volumes to the cluster.
  • Monitoring: Prometheus, Grafana, Alertmanager, and Netdata. The Homelab page shows live metrics from all three nodes, refreshed every second.
  • Data: CloudNativePG runs Postgres with nightly snapshots. Plex, Home Assistant, and n8n run alongside everything else.

It stayed up through the October 2025 AWS outage. It is also more expensive and less reliable than the cloud.


2021–2026

WARN Tracker - Python Application

A public dashboard of WARN notices, the layoff and closure filings US states require from employers. It rebuilds a spreadsheet scraper I wrote in 2021, this time with AI help.

  • Scraping: Fetching and parsing are separate steps, and every failure saves a snapshot I can replay. When a state redesigns its site, I can reproduce the broken parse and fix it quickly.
  • Enrichment: A Claude agent looks up each company with web search and free public sources. Notices usually land about 60 days before the layoff, so that is the lead time affected workers get.
  • API and dashboard: A read-only FastAPI API with a small single-page frontend for filtering notices, plus CSV export.
  • Deployment: Runs as a K3s CronJob on the homelab, with Postgres on CloudNativePG, deployed through Helm and Flux.

This site - Django Web Application

A Django rewrite of my old portfolio. It moved from cPanel shared hosting to a VPS and then home to the homelab.

  • Blog: Tags, PostgreSQL full-text search, an RSS feed, and Django admin for writing.
  • Photo gallery: Uploads, thumbnails, and Redis-backed rankings. Likes, comments, and the activity feed sit behind a login (email, Google, or Facebook).
  • Spam: Invisible reCAPTCHA v3 on the sign-up and contact forms. I haven't had a fake account since.
  • Extras: A dark mode toggle, live cluster metrics, and a weather page fed by my weather station through Home Assistant.
